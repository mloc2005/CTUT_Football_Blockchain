
# Website - CTUT Football Blockchain

Giao diện website của hệ thống ghi nhận và tra cứu kết quả thi đấu bóng đá ứng dụng Blockchain và Smart Contract.

## Công nghệ sử dụng
- HTML, CSS, JavaScript
- Ethers.js
- MetaMask
- Ethereum Sepolia Testnet
- Smart Contract Solidity (FootballResultsV3)

## Chức năng
- Hiển thị và tìm kiếm kết quả thi đấu
- Xem chi tiết trận đấu, bàn thắng và thẻ phạt
- Thống kê kết quả thi đấu
- Quản lý trận đấu thông qua MetaMask
- Tra cứu lịch sử giao dịch Blockchain
- Xác minh giao dịch trên Etherscan
